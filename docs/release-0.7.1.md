# TwinText 0.7.1

- One Display location selector now covers in-conversation Chat, floating Chat reader, and the completed-reply Desktop reader. Existing preferences, history, providers and defaults are preserved.
- Native Settings uses the window body, hiding reply and paste areas. Back restores the reader. Selecting in-conversation display keeps settings open until Back.
- Reader Translate/Original switches the current reply without changing preferences. Completed translations are reused; switching to Original cancels pending work. Floating Chat still copies the exact original Markdown.
- English, Chinese, Japanese, French and Spanish labels are included. Codex's native message toolbar is unchanged.

Google Free remains experimental and optional. Offline remains the default. Packages are source installers for Windows and Linux, not standalone executables.
